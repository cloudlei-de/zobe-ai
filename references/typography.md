# Typography intelligence

Type is where slop is won or lost. A characterful display face is zobe.ai's single strongest anti-slop signal.

## Invest in the typeface

Confident brands run a **bespoke or licensed display face**, self-hosted and loaded first in every stack. The generic Inter/Roboto/system-default look is exactly what slop defaults to.

**Rule:** never default to Inter/Roboto/system-ui as the brand *voice*. Choose a characterful face. Inter/Satoshi are acceptable **only** as a quiet body/UI workhorse *under* a distinctive display face.

When there's no licensed face yet, strong characterful options that escape the slop look (most free for commercial use):

- **Geometric grotesque** — Clash Display, Space Grotesk, General Sans, Hanken Grotesk.
- **Humanist / corporate sans** — Geist, a humanist grotesque with real character.
- **Serif display** — Fraunces, Cormorant (pair with a quiet sans).

State that a properly licensed or commissioned face would elevate it further.

## The defining move: two-pole tension

Set **display huge with negative tracking**; set **labels tiny with wide positive tracking**.

- **Display** (>48px): pull tracking `-0.02 to -0.05em` (or -0.5 to -3px). Big display can run to 120–160px in poster contexts.
- **Labels / eyebrows / buttons** (11–14px): UPPERCASE + `+0.1 to +0.2em`.
- **Body** (~16–21px): near-zero or slightly negative tracking, line-height 1.4–1.45.

This contrast does more for perceived craft than any effect.

## Weight strategy by archetype

- **Corporate / luxury** → go LIGHT for elegance: headings at weight 300–400, hairline body weights — deliberately undercutting heavy-retail shouting.
- **Editorial / social** → restrained (max ~600).
- **Bold reserved for decisive CTAs only.**

## Pairing patterns

- **Serif-display + hairline-sans = luxury** (serif headline + a thin grotesque body).
- **Single geometric grotesque pushed to poster scale = editorial / social.**
- **Humanist sans, light weights = corporate-institutional.**

## Scale & case

- Use a **fluid `clamp()` scale**, not breakpoint jumps (e.g. micro `11→12px` up to giga `34→49px`).
- **Sentence case** for editorial warmth (never ALL-CAPS shouting in body/headlines).
- **ALL-CAPS only as a deliberate poster stance** (events, social-first).

## Don't

- Font sprawl — more than two typefaces total (display + body) signals no system governance.
- Typos on prominent lines — a misspelling on the biggest headline nicks credibility instantly. Proofread.
- Under-scaled hero H1 (a 32px hero is too small for a confident archetype).
- Inter/Roboto/system-ui as the identity face.
